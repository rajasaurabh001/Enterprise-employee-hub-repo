# Enterprise Employee Hub

## Vision

Enterprise Employee Hub is a modern SharePoint Online intranet solution designed to improve employee productivity by providing a centralized digital workplace.

## Objectives

- Personalized employee dashboard
- Department news
- Company announcements
- Employee directory
- Leave management
- Quick links
- Document center
- Microsoft Teams integration

## Technology Stack

- SharePoint Framework (SPFx)
- React
- TypeScript
- Fluent UI
- PnPjs
- Microsoft Graph
- Azure
- Azure Functions
- ASP.NET Core Web API

## Architecture

Frontend:
- SPFx
- React
- TypeScript

Backend:
- Azure Functions
- ASP.NET Core API

Authentication:
- Azure AD
- Microsoft Graph
