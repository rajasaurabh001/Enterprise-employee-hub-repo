# User Stories

## Epic: Employee Dashboard

### US-001 - View Dashboard

As an employee,
I want to see a personalized dashboard when I open the portal,
So that I can quickly access important information.

---

### US-002 - Company News

As an employee,
I want to read the latest company announcements,
So that I stay informed about organizational updates.

---

### US-003 - Quick Links

As an employee,
I want quick access to frequently used applications,
So that I can save time during my daily work.

---

### US-004 - Employee Directory

As an employee,
I want to search for colleagues by name or department,
So that I can easily contact the right person.

---

### US-005 - Holiday Calendar

As an employee,
I want to view upcoming holidays,
So that I can plan my leave effectively.

---

### US-006 - Company Events

As an employee,
I want to see upcoming company events,
So that I can participate in organizational activities.

---

### US-007 - Publish News

As an HR manager,
I want to publish company news,
So that employees receive important updates.

---

### US-008 - Manage Quick Links

As an IT administrator,
I want to manage the quick links displayed on the portal,
So that employees always have access to the correct applications.

---

### US-009 - View Team Information

As a manager,
I want to quickly access information about my team,
So that I can manage my team effectively.
